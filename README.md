## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize.

## Deploy on Render

The easiest way to deploy your Next.js app on Render is by connecting your GitHub repoasitory and selecting a Web Service.

Steps:
Go to Render Dashboard.

Click "New + > Web Service".

Connect your GitHub repo (droply).

Set the following build and start commands:

Build Command: npm install && npm run build

Start Command: npm start (if using next start) or customize if needed

Environment: Node

Set Environment Variables if required (e.g., DATABASE_URL, NEXT_PUBLIC_API_URL, etc.).

Check out Render's Next.js deployment guide for more help.
